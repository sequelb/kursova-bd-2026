# Висновки

## Встановлені недоліки

В ході розробки та демонстрації системи виявлено такі недоліки:

1. *Відсутність функції видалення відгуків адміністратором та викладачем.* Наразі видалити відгук може лише автор. Для повноцінної модерації контенту необхідно додати можливість видалення відгуків адміністратором, а також можливість для викладача позначати відгуки як неприйнятні.

2. *Спрощена модель оплати.* Оплата фіксується як факт без інтеграції з платіжними системами. Комісія платформи не враховується — увесь дохід від курсу зараховується викладачу.

3. *Текстовий формат уроків.* Контент уроків обмежений текстом. Підтримка відео, зображень або інтерактивних елементів потребує розширення схеми та інфраструктури зберігання файлів.

4. *Відсутність сповіщень.* Система не інформує користувачів про події (новий запис на курс, зміна статусу виплати) поза межами поточної сесії.

## Перспективи покращення

1. *Розширення модерації.* Додати можливість видалення та приховування відгуків адміністратором, а також механізм скарг на контент.

2. *Комісія платформи.* Додати стовпець platform_fee до таблиці payments, оновити тригер обчислення балансу та додати показник «Прибуток платформи» до фінансової панелі адміністратора.

3. *Мультимедійний контент.* Розширити модель уроків для підтримки різних типів контенту (відео, зображення, код), що потребує інтеграції з файловим сховищем.

4. *Кешування рекомендацій.* Для масштабування алгоритму рекомендацій можна застосувати матеріалізоване представлення (materialized view) або окрему таблицю з періодичним оновленням.

5. *Розширення аналітики.* Додати порівняльні звіти між курсами, аналіз утримання студентів, прогнозування доходу.
